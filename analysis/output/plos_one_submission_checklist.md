# PLOS ONE Submission Checklist (Project-Specific)

## Manuscript files
- Main manuscript: `manuscript_plos_one_draft.md`
- Cover letter: `cover_letter_plos_one.md`
- Supporting outputs packet: `submission_packet_assumption_debt.zip`

## Required front matter (complete before upload)
- Full author names and affiliations
- Corresponding author details
- Short title
- Keywords
- Author contributions (CRediT)
- Funding statement
- Competing interests statement
- Data availability statement

## Methods transparency checks
- Study design and data source explicitly described
- Primary estimand and model stated
- Dependence adjustment stated (`dataset` clustering)
- Sensitivity families listed
- Conservative-null checks reported
- Non-causal interpretation boundary explicit

## Reproducibility checks
- Analysis script path stated: `analysis/assumption_debt_modeling.R`
- Output files indexed in packet manifest
- Robustness matrix and multiverse files included

## Reporting risk checks
- Abstract claims match conservative results
- Discussion avoids causal language
- Limitations include transportability and dependence among specifications

## Upload set (minimum)
- `manuscript_plos_one_draft.md`
- `cover_letter_plos_one.md`
- `submission_packet_assumption_debt.zip`
- Any required PLOS formatting forms/templates completed in submission system
